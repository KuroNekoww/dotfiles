# Micro

现代终端文本编辑器配置。

## 文件说明

- `settings.json` - 主配置文件
- `colorschemes/` - 配色方案
  - `noctalia.micro` - 当前主题，由 Noctalia 的 `micro` 模板自动生成
  - `catppuccin-*.micro` - Catppuccin 主题系列（备用，可手动切换）
- `syntax/` - 语法高亮定义
